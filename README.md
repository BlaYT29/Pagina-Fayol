## 🌐 Sitio web

La plataforma digital del **Colegio Henri Fayol** fue desarrollada con el objetivo de entregar a estudiantes, familias, docentes y comunidad educativa un acceso moderno, claro y rápido a la información del establecimiento.

🔗 **Versión publicada:**  
https://blayt29.github.io/Pagina-Fayol/

🌎 **Dominio institucional:**  
https://www.colegiofayol.cl/

---

## 🏫 Sobre el proyecto

Este proyecto corresponde al desarrollo de una nueva plataforma web para el Colegio Henri Fayol.

El sitio fue construido desde cero buscando una experiencia moderna, responsiva y de fácil administración, permitiendo mantener actualizadas las distintas áreas del colegio sin modificar constantemente la estructura principal del sitio.

Entre sus principales secciones se encuentran:

- 🏫 Información institucional
- 👨‍🏫 Equipo directivo y docentes
- 📰 Noticias
- 📸 Galería fotográfica
- 📅 Fechas importantes
- 🕐 Horarios
- 📄 Reglamentos y protocolos
- 🎓 Admisión Escolar 2027
- 📍 Ubicación del establecimiento
- 📞 Información de contacto
- ✉️ Formulario de consultas
- 🔔 Sistema de avisos mediante popup

---

## ✨ Características

La plataforma incorpora distintas funcionalidades orientadas a mejorar la experiencia de la comunidad educativa.

### Diseño responsivo

El sitio se adapta a:

- Computadores
- Notebooks
- Tablets
- Smartphones

### Contenido dinámico

Gran parte del contenido se administra mediante archivos JSON, permitiendo modificar información sin alterar directamente la estructura HTML.

Esto incluye:

- Noticias
- Galería
- Profesores
- Fechas importantes
- Información institucional
- Admisión
- Estadísticas
- Avisos emergentes

### Galería

Sistema de galería fotográfica con:

- Categorías
- Visualización ampliada
- Navegación entre fotografías
- Lightbox
- Soporte para teclado

### Noticias

Sistema de noticias dinámicas con páginas individuales y contenido administrado mediante JSON.

### Documentos

Acceso directo a:

- Reglamentos
- Protocolos
- Documentos de admisión
- Información institucional

Los documentos pueden visualizarse o descargarse directamente desde el sitio.

### Admisión Escolar

Sección especial dedicada al proceso de **Admisión Escolar 2027**, incluyendo:

- Etapas del proceso
- Información para las familias
- Documentos
- Antecedentes
- Formas de contacto

### Formulario de contacto

Formulario de consultas que permite enviar mensajes directamente al correo institucional del Colegio Henri Fayol.

## ⚙️ Administración del contenido

La información dinámica se encuentra principalmente en:

    data/

Desde estos archivos se pueden administrar diferentes áreas del sitio.

### Noticias

    data/noticias.json

### Galería

    data/galeria.json

### Profesores

    data/profesores.json

### Fechas importantes

    data/fechas.json

### Información institucional

    data/colegio.json

### Admisión

    data/admision.json

### Popup

    data/popup.json

Este sistema permite mantener el sitio actualizado de una manera sencilla y organizada.
